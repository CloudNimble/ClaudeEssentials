## Summary

Represents the type of instruction memory file loaded in Claude Code.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `User` | 0 | A user-level instruction file (e.g., ~/.claude/CLAUDE.md). |
| `Project` | 1 | A project-level instruction file checked into the repository. |
| `Local` | 2 | A local instruction file that is not checked into version control. |
| `Managed` | 3 | A managed instruction file maintained by a plugin or external system. |
