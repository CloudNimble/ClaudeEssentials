## Summary

Represents the permission mode under which Claude Code is operating.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `Default` | 0 | Standard behavior that prompts for dangerous operations. |
| `AcceptEdits` | 1 | Automatically accepts file edit operations. |
| `BypassPermissions` | 2 | Bypasses all permission checks. Use with caution. |
| `Plan` | 3 | Plans without executing changes. |
| `DontAsk` | 4 | Denies anything that is not already allowed instead of prompting. |
| `Auto` | 5 | Claude Code makes permission decisions without prompting the user. |
