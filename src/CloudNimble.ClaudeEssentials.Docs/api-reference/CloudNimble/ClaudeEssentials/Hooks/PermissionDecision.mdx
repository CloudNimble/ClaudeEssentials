## Summary

Represents a permission decision returned by a PreToolUse or PreModelSwitch hook.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `Allow` | 0 | Allows the action without prompting the user. |
| `Deny` | 1 | Denies the action and informs Claude of the reason. |
| `Ask` | 2 | Asks the user to confirm the action. |
| `Defer` | 3 | Defers the decision to the normal permission flow. |
