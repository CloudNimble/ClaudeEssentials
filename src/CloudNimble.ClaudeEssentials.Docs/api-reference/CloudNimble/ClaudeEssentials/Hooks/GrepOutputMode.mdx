## Summary

Represents the output mode for grep search results. [GrepOutputMode.FilesWithMatches](/api-reference/CloudNimble/ClaudeEssentials/Hooks/GrepOutputMode#fileswithmatches) is the default.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `FilesWithMatches` | 0 | Returns only the paths of files that contain at least one match. This is the default output mode. |
| `Content` | 1 | Returns the matching lines from each file along with their file paths. |
| `Count` | 2 | Returns the number of matches found in each file. |
