## Summary

Represents the Agent tool response when the agent was launched in the background
and has not yet completed.

## Remarks

Use the [AsyncLaunchedAgentToolResponse.OutputFile](/api-reference/CloudNimble/ClaudeEssentials/Hooks/Tools/Responses/AsyncLaunchedAgentToolResponse#outputfile) path or the TaskOutput tool with the [AsyncLaunchedAgentToolResponse.AgentId](/api-reference/CloudNimble/ClaudeEssentials/Hooks/Tools/Responses/AsyncLaunchedAgentToolResponse#agentid)
to check the agent's progress and retrieve results once it completes.

Example JSON payload:
```csharp
{
  "status": "async_launched",
  "agentId": "agent_01ABC123",
  "description": "Explore codebase structure",
  "prompt": "Find all TypeScript files that import React",
  "outputFile": "/tmp/agent_01ABC123.jsonl",
  "canReadOutputFile": true
}
```
