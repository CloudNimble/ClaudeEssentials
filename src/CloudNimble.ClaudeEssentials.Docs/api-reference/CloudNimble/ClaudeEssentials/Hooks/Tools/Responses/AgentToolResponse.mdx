## Summary

Represents the response payload returned by the Claude Code Agent tool.
This is a polymorphic base type — the actual response will be either
[CompletedAgentToolResponse](/api-reference/CloudNimble/ClaudeEssentials/Hooks/Tools/Responses/CompletedAgentToolResponse) or [AsyncLaunchedAgentToolResponse](/api-reference/CloudNimble/ClaudeEssentials/Hooks/Tools/Responses/AsyncLaunchedAgentToolResponse)
depending on whether the agent ran synchronously or was launched in the background.

## Remarks

The discriminator is the `"status"` field in the JSON payload:

- `"completed"` — The agent finished and returned its results inline
- `"async_launched"` — The agent was launched in the background
