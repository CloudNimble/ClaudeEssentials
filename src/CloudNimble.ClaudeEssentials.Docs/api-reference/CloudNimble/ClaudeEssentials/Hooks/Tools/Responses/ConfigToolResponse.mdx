## Summary

Represents the response payload returned by the Claude Code Config tool after
getting or setting a configuration value.

## Remarks

Example JSON payload (get):
```csharp
{
  "success": true,
  "operation": "get",
  "setting": "theme",
  "value": "dark"
}
```

Example JSON payload (set):
```csharp
{
  "success": true,
  "operation": "set",
  "setting": "theme",
  "previousValue": "light",
  "newValue": "dark"
}
```
