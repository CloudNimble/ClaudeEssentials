## Summary

Represents the result of an MCP tool execution.

## Remarks

The result is an untagged union, so exactly one of [McpToolResponse.Text](/api-reference/CloudNimble/ClaudeEssentials/Hooks/Tools/Responses/McpToolResponse#text), [McpToolResponse.ContentBlocks](/api-reference/CloudNimble/ClaudeEssentials/Hooks/Tools/Responses/McpToolResponse#contentblocks), or
[McpToolResponse.StructuredContent](/api-reference/CloudNimble/ClaudeEssentials/Hooks/Tools/Responses/McpToolResponse#structuredcontent) is populated, according to the JSON shape that the tool returned.

## Examples

```csharp
var payload = ClaudeHooksSerializer.DeserializeMcpPostToolUse(json);
var text = payload?.ToolResponse?.Text;
```
