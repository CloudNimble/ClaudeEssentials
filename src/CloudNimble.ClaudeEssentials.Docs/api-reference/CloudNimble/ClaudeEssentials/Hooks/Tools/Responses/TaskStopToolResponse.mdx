## Summary

Represents the response payload returned by the Claude Code TaskStop tool after
stopping a running background task.

## Remarks

Example JSON payload:
```csharp
{
  "message": "Task stopped successfully",
  "task_id": "task_abc123",
  "task_type": "shell",
  "command": "npm run dev"
}
```
