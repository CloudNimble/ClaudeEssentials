## Summary

Represents an aggregate breakdown of the tools used by an Agent during its execution.

## Remarks

These counts give a high-level view of the agent's workload, useful for understanding
whether the agent spent its time searching, reading, editing, or running shell commands.

The [AgentToolStats.LinesAdded](/api-reference/CloudNimble/ClaudeEssentials/Hooks/Tools/Responses/AgentToolStats#linesadded) and [AgentToolStats.LinesRemoved](/api-reference/CloudNimble/ClaudeEssentials/Hooks/Tools/Responses/AgentToolStats#linesremoved) counts aggregate line-level
changes across all Edit/Write operations performed by the agent.

Example JSON payload:
```csharp
{
  "readCount": 12,
  "searchCount": 5,
  "bashCount": 3,
  "editFileCount": 4,
  "linesAdded": 87,
  "linesRemoved": 23,
  "otherToolCount": 2
}
```
