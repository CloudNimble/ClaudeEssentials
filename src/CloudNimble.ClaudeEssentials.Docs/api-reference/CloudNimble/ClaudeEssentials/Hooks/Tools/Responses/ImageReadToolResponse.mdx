## Summary

Represents the Read tool response for an image file (PNG, JPG, GIF, WebP).

## Remarks

Image content is returned as base64-encoded data. Claude is a multimodal LLM and can
process image data directly.

Example JSON payload:
```csharp
{
  "type": "image",
  "file": {
    "base64": "iVBORw0KGgo...",
    "type": "image/png",
    "originalSize": 24576,
    "dimensions": {
      "originalWidth": 1920,
      "originalHeight": 1080,
      "displayWidth": 960,
      "displayHeight": 540
    }
  }
}
```
