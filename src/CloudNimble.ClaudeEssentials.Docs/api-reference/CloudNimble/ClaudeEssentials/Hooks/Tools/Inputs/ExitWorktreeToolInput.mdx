## Summary

Represents the input parameters for the ExitWorktree tool.
The ExitWorktree tool exits and optionally removes a git worktree.

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> Action

Gets or sets the action to take. [WorktreeAction.Keep](/api-reference/CloudNimble/ClaudeEssentials/Hooks/WorktreeAction#keep) leaves the worktree
and branch on disk; [WorktreeAction.Remove](/api-reference/CloudNimble/ClaudeEssentials/Hooks/WorktreeAction#remove) deletes both.

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> DiscardChanges

Gets or sets whether to force removal when the worktree has uncommitted files or unmerged commits.
Required to be `true` when [ExitWorktreeToolInput.Action](/api-reference/CloudNimble/ClaudeEssentials/Hooks/Tools/Inputs/ExitWorktreeToolInput#action) is `"remove"` and there are uncommitted
files or unmerged commits. The tool will refuse and list them otherwise.

#### Syntax
