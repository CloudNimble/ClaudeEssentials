## Summary

Represents the input parameters for the Agent tool.
The Agent tool launches specialized agents (subprocesses) that autonomously handle complex tasks.

## Remarks

Each agent type has specific capabilities and tools available to it.
Available agent types include: general-purpose, Explore, Plan, claude-code-guide, and others.

This type reflects the latest Agent tool schema including
team collaboration fields such as [AgentToolInput.Name](/api-reference/CloudNimble/ClaudeEssentials/Hooks/Tools/Inputs/AgentToolInput#name), [AgentToolInput.TeamName](/api-reference/CloudNimble/ClaudeEssentials/Hooks/Tools/Inputs/AgentToolInput#teamname), and [AgentToolInput.Mode](/api-reference/CloudNimble/ClaudeEssentials/Hooks/Tools/Inputs/AgentToolInput#mode).
