## Summary

Represents the input parameters for the Config tool.
The Config tool gets or sets Claude Code configuration settings.

## Remarks

When [ConfigToolInput.Value](/api-reference/CloudNimble/ClaudeEssentials/Hooks/Tools/Inputs/ConfigToolInput#value) is omitted, the tool returns the current value of the setting.
When [ConfigToolInput.Value](/api-reference/CloudNimble/ClaudeEssentials/Hooks/Tools/Inputs/ConfigToolInput#value) is provided, the tool updates the setting to the new value.

Example JSON (get):
```csharp
{ "setting": "theme" }
```

Example JSON (set):
```csharp
{ "setting": "permissions.defaultMode", "value": "plan" }
```
