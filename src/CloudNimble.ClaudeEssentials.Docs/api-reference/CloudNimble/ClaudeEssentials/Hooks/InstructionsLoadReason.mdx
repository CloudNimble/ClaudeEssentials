## Summary

Represents the reason why an instruction file was loaded in Claude Code.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `SessionStart` | 0 | The instruction file was loaded during session start. |
| `NestedTraversal` | 1 | The instruction file was loaded by traversing nested directories. |
| `PathGlobMatch` | 2 | The instruction file was loaded because a path glob pattern matched. |
| `Include` | 3 | The instruction file was loaded because it was included by another instruction file. |
| `Compact` | 4 | The instruction file was reloaded after a compact operation. |
