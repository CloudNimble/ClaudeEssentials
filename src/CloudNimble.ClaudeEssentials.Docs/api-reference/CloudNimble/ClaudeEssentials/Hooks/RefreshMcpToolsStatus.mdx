## Summary

Represents the outcome of refreshing the tool list of an MCP server.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `Refreshed` | 0 | The tool list was re-queried and applied. |
| `Error` | 1 | The re-query failed and the previous tool set was kept. |
| `NotConnected` | 2 | The server has no live connection to query. This tool never dials. |
