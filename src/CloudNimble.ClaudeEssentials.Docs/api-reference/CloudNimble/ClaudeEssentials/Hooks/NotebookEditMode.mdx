## Summary

Represents the edit operation mode applied to a Jupyter notebook cell.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `Replace` | 0 | Replaces the content of an existing cell. |
| `Insert` | 1 | Inserts a new cell at the specified position. |
| `Delete` | 2 | Deletes the cell at the specified position. |
