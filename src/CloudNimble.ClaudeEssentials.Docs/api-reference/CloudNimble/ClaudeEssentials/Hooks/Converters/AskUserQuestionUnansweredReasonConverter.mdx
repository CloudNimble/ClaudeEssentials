## Summary

Converts the `unanswered` field of an AskUserQuestion annotation to and from a nullable [AskUserQuestionUnansweredReason](/api-reference/CloudNimble/ClaudeEssentials/Hooks/AskUserQuestionUnansweredReason).

## Remarks

The schema instructs consumers to treat any unrecognized value as absent, so this converter reads unknown
values as [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null) rather than throwing as the default enum handling would.
