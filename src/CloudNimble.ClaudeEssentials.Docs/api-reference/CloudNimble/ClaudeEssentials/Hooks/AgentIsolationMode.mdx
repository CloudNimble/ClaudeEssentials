## Summary

Represents the isolation mode used when spawning an agent.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `Worktree` | 0 | Creates a temporary git worktree so the agent works on an isolated copy of the repo. |
| `Remote` | 1 | Launches the agent in a remote cloud environment. The agent always runs in the background. |
