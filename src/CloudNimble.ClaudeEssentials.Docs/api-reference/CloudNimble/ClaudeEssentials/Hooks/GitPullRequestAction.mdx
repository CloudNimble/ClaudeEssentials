|------|-------|-------------|
| `Created` | 0 | The pull request was created. |
| `Edited` | 1 | The pull request was edited. |
| `Merged` | 2 | The pull request was merged. |
| `Commented` | 3 | A comment was added to the pull request. |
| `Closed` | 4 | The pull request was closed. |
| `Reopened` | 5 | The pull request was reopened. |
| `Ready` | 6 | The pull request was marked ready for review. |
| `Draft` | 7 | The pull request was converted to a draft. |
| `AutoMergeEnabled` | 8 | Auto-merge was enabled on the pull request. |
| `AutoMergeDisabled` | 9 | Auto-merge was disabled on the pull request. |
