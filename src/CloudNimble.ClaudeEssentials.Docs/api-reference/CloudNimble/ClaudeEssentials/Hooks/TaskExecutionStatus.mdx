## Summary

Represents the execution status of a Claude Code task. Named `TaskExecutionStatus` to avoid
collision with [TaskStatus](https://learn.microsoft.com/dotnet/api/system.threading.tasks.taskstatus).

## Values

| Name | Value | Description |
|------|-------|-------------|
| `Completed` | 0 | The task finished successfully. |
| `Running` | 1 | The task is currently executing. |
| `Error` | 2 | The task encountered an error during execution. |
| `Interrupted` | 3 | The task was stopped before it could finish. |
